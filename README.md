# Solirestaurant – Application Web de Gestion de Commandes pour Restaurant 

**Solirestaurant** est une application PHP conçue pour faciliter la gestion des menus, commandes et utilisateurs dans un restaurant. Ce projet met l’accent sur l’accessibilité, la simplicité d’utilisation et la clarté du code.

## Fonctionnalités principales

### Authentification sécurisée
- Connexion des utilisateurs avec vérification du mot de passe
- Gestion des sessions
- Inscriptions sécurisées avec mot de passe haché

### Gestion des menus et plats
- Ajout, modification et suppression de plats
- Catégorisation des plats (entrée, plat, dessert, boisson, etc.)
- Affichage clair et structuré pour les utilisateurs

### Système de commande
- Création de commandes par les utilisateurs
- Visualisation des détails de commande
- Gestion de l’état des commandes (en cours, livrée, annulée)

### Gestion des utilisateurs
- Rôles : administrateur, client
- Interface d’administration pour gérer les utilisateurs et les plats

### Tableau de bord
- Résumé des commandes du jour
- Statistiques simples : nombre de plats vendus, revenus estimés, fréquentation
- Filtres par date ou utilisateur

---

## Technologies utilisées

- **Langage** : PHP 
- **Base de données** : MySQL
- **Frontend** : HTML / CSS / JavaScript
